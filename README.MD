Pour démarrer le projet, faire un venv python et pip install -r requirement.txt puis lancer avec python -m src.render.m

Le curseur est mit de base sur faire spawn une boule pour faire apparaitre du sable ou autre, il faut se référencer 
au fichier debug qui indique toute les commandes possibles.
Pour accéder au mode debug il faut aller dans la console et marqué les commandes
